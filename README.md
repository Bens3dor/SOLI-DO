# SOLI-DO

## Descripción
"Elegimos 'Calculator'(Calculadora) porque resuelve la necesidad de contar con una herramienta accesible en línea para realizar cálculos matemáticos cotidianos (suma, resta, multiplicación y división) de forma inmediata."
 
## User Stories
- Como usuario, quiero ver una pantalla que muestre los números ingresados y los resultados de las operaciones.
- Como usuario, quiero hacer clic en los botones de los dígitos (0-9) para ingresar los números.
- Como usuario, quiero hacer clic en los botones de las cuatro operaciones básicas (+, -, ×, ÷) para realizar cálculos.
- Como usuario, quiero un botón de igual (=) para ejecutar y visualizar el resultado de la operación.
- Como usuario, quiero un botón para limpiar/borrar la pantalla (C / AC) para reiniciar mis cálculos o corregir errores.
- Como usuario, quiero poder ingresar un punto decimal (.) para realizar operaciones con números no enteros.
 
## Metodología
Enfoque ágil (Scrum / Kanban) — "Elegimos una metodología ágil (Kanban) porque, al ser un equipo de 3 integrantes con tiempo limitado, nos permite trabajar mediante un proceso de prueba y error e iteraciones cortas, lo cual nos ayuda a entender y corregir el código conforme avanzamos. Además, las User Stories de la Calculadora se prestan para construir la aplicación por partes (primero la interfaz y luego las operaciones), y el uso del tablero en GitHub Projects nos facilita visualizar y repartir el progreso del equipo en tiempo real."
